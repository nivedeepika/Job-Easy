# Job-Easy
# 💼 JobEasy – Smart Job Portal

JobEasy is a modern web-based job portal that enables users to search, filter, and apply for jobs based on location, experience, and job title. It features an intuitive UI, user profile management, and dynamic job listings.
![Job_Portal](https://github.com/user-attachments/assets/0504b0f2-1791-4c0d-8921-fb0cd5928b5d)


---

## 🚀 Features

- 🔍 **Search & Filter Jobs** – by title, experience level, and location
- 👨‍💼 **User Profile Management** – update and manage user profiles
- 📄 **Job Listings** – scrollable job cards with detailed info
- ✅ **Apply Functionality** – users can directly apply for jobs
- 🎨 **Responsive UI** – mobile and desktop friendly

---

## 🛠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python (Flask)  
- **Database**: MongoDB  
- **Styling**: Custom CSS
